## 3. Coverage checklist

### Visual
- [ ] Text contrast checked against actual colors.
- [ ] Meaningful graphical components checked.
- [ ] Information not communicated by color alone.
- [ ] Text scaling and reflow considered.
- [ ] Focus and selection states distinguishable.

### Motor
- [ ] Touch targets measured.
- [ ] Adequate target spacing.
- [ ] No essential drag-only or precision-only task.
- [ ] Primary actions reachable and consistent.

### Screen-reader-aware design
- [ ] Icon controls have accessible names specified.
- [ ] Reading/focus order documented.
- [ ] Form labels and errors specified.
- [ ] State changes have a planned announcement.
- [ ] Heading/content structure remains meaningful.

### Auditory/communication
- [ ] Essential audio has text alternative where needed.
- [ ] Video has captions/transcript where relevant.
- [ ] Notifications are not audio-only.
- [ ] Communication alternatives considered.

### Cognitive/language
- [ ] Plain language used.
- [ ] Predictable navigation.
- [ ] Instructions are concise and contextual.
- [ ] Errors are recoverable.
- [ ] Choice complexity is manageable.

### Privacy and dignity
- [ ] Sensitive data is minimized.
- [ ] Consent and visibility are clear.
- [ ] Sharing is user-controlled where appropriate.
- [ ] No unnecessary disability disclosure is required.
